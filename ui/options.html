SpamGuard 設定

基本

導入直後は「タグを付ける」で数日運用し、ログで誤検出がないことを確認してから移動を有効にしてください。

しきい値

ローカルルールの点数がグレーゾーンに入った分だけJevへ問い合わせます。範囲を狭めるほどAPI呼び出しは減ります。

Jev（TypeSafe System One）連携

APIキーはこのプロファイル内（storage.local）に平文で保存されます。本文の抜粋・件名・差出人情報がTypeSafeへ送信される点に留意してください。

拒否リスト

詐称ではないが読みたくない正規のメルマガ・通知を、差出人名指しで迷惑扱いにします。内容ルールでは落とせない（落とすと同じ送信元の本物の重要通知まで巻き込む）ため、この仕組みで処理します。

許可リスト

設定のバックアップ

アドオンを入れ直すとき、いったんアンインストールすると保存済みの設定（APIキーを含む）は消えます。更新前に書き出しておいてください。

書き出したファイルにはAPIキーが平文で含まれます。保管場所に注意してください。

拒否リストの候補

判定ログの中で繰り返し迷惑と判定された差出人を拾って提示します。自動では登録しません。差出人は毎回使い捨てのアドレスを使うため（実データで98.6%が1回きり）、自動登録はほとんど効果がなく、誤検知を永続化させる副作用のほうが大きいためです。

回数単位差出人直近の件名操作

フリーメール（gmail.com / outlook.com 等）とご自身のドメインは、正規のメールを巻き込むため候補から除外しています。
